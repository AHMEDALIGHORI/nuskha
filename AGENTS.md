# Nuskha

AI prescription guardian. Photograph a handwritten prescription, hear plain-language explanations in Urdu, get warned about dangerous combinations, find cheaper registered generics, and build a daily reminder schedule.

Stack: Next.js App Router + TypeScript + Tailwind + Framer Motion, Gemini API, deployed on Vercel.

## Design system

For any UI, copy, or visual work, in this order:

1. Read `DESIGN.md` for direction: palette, typography, dials, layout principles, voice.
2. Read `design/antislop/antislop.md` (core filter), then the skill for the task:
   - UI / visual: `design/antislop/skills/antislop-ui/SKILL.md`
   - Copy & text: `design/antislop/skills/antislop-copywriting/SKILL.md`
   - People / accessibility: `design/antislop/skills/antislop-human/SKILL.md`
   - Mobile / responsive: `design/antislop/skills/antislop-layoutmobile/SKILL.md`
   - Code comments: `design/antislop/skills/antislop-code/SKILL.md`
3. UI/UX Pro Max design intelligence is installed under `.qoder/`.

antislop active: during (session override).

## Safety framing

Nuskha is an awareness tool. It never diagnoses, never changes doses, and every result screen carries: Nuskha explains your prescription. Your doctor and pharmacist make the decisions.
